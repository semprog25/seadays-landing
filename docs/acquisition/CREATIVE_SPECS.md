# SeaDays creative system (reuse brand, do not restyle)

Brand: dark `#0a0a0a`, neon red `#FF0033`, white type, existing ship wordmark (`/logo.png`, `/press/logos/`). No new brand system.

Honest claims only: cruise planner, ship/port guides, packing, expenses, Cruise Passport, crew tools, 11 languages, free tier + optional premium. **Do not claim** live AIS, offline maps, guaranteed excursion booking, or “#1 cruise app”.

## Concepts

1. **Your whole cruise in one place.** Itinerary + packing + ports.
2. **Know your ship before you sail.** Dining, amenities, layout — catalog guides.
3. **Plan every port day.** Shore-day notes without a pile of screenshots.
4. **Never forget what happens next.** Day-by-day voyage + countdown.
5. **Your cruise companion.** Before, during, after.
6. **First cruise? Start here.** Packing, documents, first port day.
